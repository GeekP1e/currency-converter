# Версия для Opera

Это исходный код расширения для Opera (Chromium Manifest V3). Для полной инструкции, политики конфиденциальности и сведений о Firefox смотрите [корневой README](../README.md).

## Локальная проверка

1. Откройте `opera:extensions`.
2. Включите **Developer Mode**.
3. Нажмите **Load unpacked**.
4. Выберите эту папку `opera/` — в ней находится `manifest.json`.

Для публикации загрузите содержимое этой папки в Opera Add-ons. Firefox-пакет `.xpi` в Opera не используется.
