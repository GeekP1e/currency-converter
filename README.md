# Точный конвертер валют для Firefox

Конвертирует KZT, RUB, USD, EUR и CNY по официальным курсам Национального Банка Казахстана.
Переключатель в правом верхнем углу включает светлую или тёмную тему; выбор запоминается.
Иконка — собственный векторный рисунок милого калькулятора, без внешних изображений.

## Установка для проверки

1. Откройте в Firefox `about:debugging`.
2. Выберите «Этот Firefox».
3. Нажмите «Загрузить временное дополнение».
4. Выберите файл `manifest.json` из папки расширения.

Временное расширение удаляется после перезапуска Firefox. Для постоянной установки пакет необходимо подписать через Mozilla Add-ons.

## Как считается курс

Источник: `https://nationalbank.kz/rss/rates_all.xml`.

В XML курс каждой иностранной валюты указан в тенге. Конвертация A → B рассчитывается так:

`сумма × цена_A_в_KZT ÷ цена_B_в_KZT`

Значение делится на `quant`, поэтому курсы, опубликованные сразу за несколько единиц валюты, обрабатываются корректно. Данные кэшируются на 6 часов; при недоступности источника используется последний сохранённый курс с явным предупреждением.
