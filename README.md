# Точный конвертер валют

Расширение для **Firefox** и **Opera**. Конвертирует KZT, RUB, USD, EUR и CNY по официальным курсам Национального Банка Казахстана.

## Возможности

- Конвертация между KZT, RUB, USD, EUR и CNY.
- Официальные курсы Национального Банка Казахстана.
- Корректная обработка курсов, опубликованных за несколько единиц валюты (`quant`).
- Светлая и тёмная темы — выбор сохраняется.
- Кэширование курсов на 6 часов. Если источник временно недоступен, используется последний сохранённый курс с предупреждением.
- Расширение не собирает и не передаёт персональные данные.

## Структура репозитория

```text
currency-converter/
├── firefox/  # исходный код версии для Firefox
├── opera/    # исходный код версии для Opera (Chromium)
└── README.md
```

В каждой папке браузера есть свой `manifest.json`. Для локальной проверки или упаковки открывайте именно нужную папку, а не корень репозитория.

## Установка

### Firefox

Для обычной постоянной установки используйте подписанный Mozilla файл `.xpi` из [Releases](https://github.com/GeekP1e/currency-converter/releases).

1. Скачайте `.xpi`.
2. Откройте Firefox → `about:addons`.
3. Нажмите шестерёнку → **«Установить дополнение из файла…»**.
4. Выберите скачанный `.xpi`.

Для проверки исходников: откройте `about:debugging` → **«Этот Firefox»** → **«Загрузить временное дополнение…»** и выберите `firefox/manifest.json`. Временное дополнение удалится после перезапуска Firefox.

### Opera

Для локального использования:

1. Откройте `opera:extensions`.
2. Включите **Developer Mode**.
3. Нажмите **Load unpacked**.
4. Выберите папку `opera/`, в которой лежит `manifest.json`.

Firefox-файл `.xpi` не подходит для Opera: это отдельные пакеты и отдельная публикация.

## Как рассчитывается курс

Источник данных — [официальный XML-канал Национального Банка Казахстана](https://nationalbank.kz/rss/rates_all.xml).

Нацбанк публикует стоимость каждой иностранной валюты в тенге. Конвертация из валюты A в валюту B рассчитывается так:

```text
сумма × цена_A_в_KZT ÷ цена_B_в_KZT
```

Перед расчётом курс делится на поле `quant`, поэтому корректно обрабатываются курсы, опубликованные, например, сразу за 100 единиц валюты.

## Конфиденциальность

Расширение запрашивает только публичные курсы на `nationalbank.kz`. Локально сохраняются выбранная тема и кэш курсов. Персональные данные не собираются.
