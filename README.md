# Точный конвертер валют для Firefox

Компактное Firefox-расширение для конвертации KZT, RUB, USD, EUR и CNY по официальным курсам Национального Банка Казахстана.

![Firefox](https://img.shields.io/badge/Firefox-109%2B-orange?logo=firefox-browser&logoColor=white)
![Manifest V3](https://img.shields.io/badge/Manifest-V3-5b6bff)

## Возможности

- Конвертация между KZT, RUB, USD, EUR и CNY.
- Официальные курсы Национального Банка Казахстана.
- Корректная обработка курсов, опубликованных за несколько единиц валюты (`quant`).
- Светлая и тёмная темы с сохранением выбора.
- Кэширование курсов на 6 часов и показ последнего сохранённого значения, если источник временно недоступен.
- Никакие персональные данные не собираются и не передаются.

## Установка

Для постоянной установки нужен файл расширения с расширением `.xpi`, подписанный Mozilla.

1. Скачайте подписанный файл `.xpi` из раздела [Releases](https://github.com/GeekP1e/currency-converter/releases) этого репозитория.
2. Откройте Firefox и перейдите на страницу `about:addons`.
3. Нажмите на значок шестерёнки.
4. Выберите **«Установить дополнение из файла…»**.
5. Выберите скачанный файл `.xpi` и подтвердите установку.

После установки расширение остаётся в Firefox и работает после перезапуска браузера.

> Файл `.zip` из исходников не предназначен для обычной установки в Firefox. Для постоянной установки используйте только подписанный `.xpi`.

## Запуск для разработки

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/GeekP1e/currency-converter.git
   ```

2. Откройте в Firefox `about:debugging`.
3. Выберите **«Этот Firefox»**.
4. Нажмите **«Загрузить временное дополнение…»**.
5. Выберите файл `manifest.json` в папке проекта.

Такое расширение удаляется после полного перезапуска Firefox — это нормальный режим разработки.

## Как рассчитывается курс

Источник данных: [официальный XML-канал Национального Банка Казахстана](https://nationalbank.kz/rss/rates_all.xml).

Нацбанк публикует стоимость каждой иностранной валюты в тенге. Конвертация из валюты A в валюту B рассчитывается так:

```text
сумма × цена_A_в_KZT ÷ цена_B_в_KZT
```

Перед расчётом курс делится на поле `quant`. Поэтому расширение правильно работает, даже если Нацбанк укажет стоимость не за одну, а, например, за 100 единиц валюты.

## Конфиденциальность

Расширение не собирает персональные данные. Оно запрашивает только публичный курс валют у `nationalbank.kz` и локально сохраняет выбранную тему и кэш курсов.
